# CubeRog

一款快節奏的 **Roguelike 射擊遊戲**，你將控制藍色方塊，在潮水般的敵人圍攻中生存，不斷升級強化，挑戰強大的 BOSS，解鎖更多章節。

---

## 🎮 遊戲特色

- **自動瞄準射擊**：無需瞄準，專注走位與策略
- **豐富的敵人類型**：
  - 紅色方塊：基礎敵人，緩慢靠近
  - 衝鋒方塊：速度極快，傷害高
  - 裝甲方塊：巨大且厚血，威脅巨大
  - 狙擊手 BOSS：遠程攻擊，多種彈幕
- **升級強化系統**：每升一級可從三種隨機強化中選擇，組合出專屬流派
- **章節挑戰**：通過第一章解鎖第二章，難度與獎勵逐步提升
- **永久成長**：使用金幣永久提升攻擊力與生命值

## 🚀 如何開始

1. 下載或克隆本倉庫
2. 使用瀏覽器打開 `index.html`
3. 在主頁選擇章節，點擊「開始戰鬥」
4. 擊敗敵人，獲取經驗升級，挑戰 BOSS！

**無需任何服務器環境，即開即玩。**

## 🧠 遊戲機制詳解

### 經驗與升級
- 擊殺敵人獲得經驗值
- 經驗條滿時提升等級，並從三個隨機強化中選擇一個
- 強化效果包括：射速提升、傷害增加、子彈數量增多、彈射、散射、移動速度提升、生命上限增加等

### 金幣與永久強化
- 戰鬥結束後根據生存時間與擊殺數結算金幣
- 在主頁「強化」頁籤中使用金幣升級「核心屬性」，永久提升所有戰鬥中的攻擊力與生命值

### 敵人生成邏輯
- 敵人會隨著時間推移越來越強（生命值與攻擊力按時間倍增）
- 每分鐘會生成數個裝甲方塊
- 第一章在 5 分鐘時會出現最終 BOSS

## 🛠️ 開發技術

- **前端**：HTML5 Canvas、CSS3、原生 JavaScript
- **存儲**：localStorage 保存金幣、強化等級、最高紀錄
- **動畫**：requestAnimationFrame 實現流暢幀動畫
- **無依賴**：純原生實現，無需任何第三方庫

## 🐛 已知問題與未來計劃

### 已知問題
- 幀率波動可能影響碰撞傷害（高幀率下傷害略高）
- 子彈彈射時可能遺留永不消失的子彈
- 升級面板與死亡畫面可能同時出現

### 未來計劃

- 新增武器系統（可切換射擊模式）
- 添加音效與背景音樂
